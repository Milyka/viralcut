# KrlzCut

Локальное приложение для нарезки длинных видео и стримов на короткие клипы для Shorts, Reels и TikTok. Вся обработка идёт на вашем компьютере через FFmpeg и Whisper — видео никуда не загружается.

## Скачать

- **Windows 10/11 (x64):** [последний релиз на GitHub](https://github.com/Milyka/viralcut/releases/latest)
- Распакуйте архив и запустите `KrlzCut.exe` (FFmpeg, модель Whisper Small и шрифты уже внутри).

## Основные возможности

- **Три режима работы:** нарезка по речи с ИИ-пресетами (8 сценариев), захват и нарезка прямых эфиров, быстрая равномерная нарезка через FFmpeg без транскрипции.
- **Источники:** локальные видео- и аудиофайлы, YouTube (с выбором качества и аудиодорожки), Twitch, VK, Rutube, прямые ссылки.
- **Редактор клипа:**
  - **Слой игры (Split-Screen):** добавление фонового ролика снизу, пропорции `50/50`–`70/30`, зум и панорамирование, микс звука.
  - **Таймлайн с раскадровкой:** точная обрезка начала и конца клипа.
  - **Субтитры:** живой предпросмотр и перетаскивание мышью прямо на кадре, 5 анимаций (`Нет`, `Pop`, `Fade`, `Slide`, `Bounce`), выбор шрифта (и загрузка своих TTF/OTF), цвет акцента и настройка обводки.
  - **Описание и хэштеги:** генерация подписи и экспорт в MP4, ZIP или SRT.
- **Модели Whisper:** выбор, скачивание и удаление локальных моделей (`Small`, `Medium`, `Large v3 Turbo`) в настройках.
- **Темы оформления:** несколько тёмных тем и своя 2-цветная палитра.

## Запуск из исходников

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-desktop.txt
python desktop/main.py
```

Для веб-версии в браузере:

```bash
uvicorn viralcut.main:app --host 127.0.0.1 --port 8765
```

## Сборка для Windows

```bash
pip install pyinstaller
pyinstaller ViralCut.spec --noconfirm --clean
```

Готовое приложение появится в папке `dist/KrlzCut/KrlzCut.exe`.
