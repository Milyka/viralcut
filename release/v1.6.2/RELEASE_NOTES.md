# ViralCut 1.6.2 (Hotfix)

Срочное исправление критического вылета `ViralCut.exe` (`0xc0000005` в `MSVCP140.dll`) при запуске распознавания речи и нарезки видео на Windows.

## Что исправлено

- **Устранён краш при создании видео (`MSVCP140.dll 14.36` / `0xc0000005`):** PyInstaller ранее упаковывал в `_internal\` устаревшую копию `msvcp140.dll` (`14.36`) из зависимостей, несовместимую с `ctranslate2` / `faster-whisper` (собранными под VC++ 2022 `14.40+` с `constexpr std::mutex`). Теперь `ViralCut.spec` принудительно упаковывает единый актуальный рантайм VC++ (`msvcp140*.dll`, `vcruntime140*.dll` версии `14.40+`) из `System32`.
- **Проверка в CI:** добавлена автоматическая проверка версии `msvcp140.dll >= 14.40` после сборки в GitHub Actions.

## Установка (Windows 10/11 x64)

1. Скачайте `ViralCut-1.6.2-windows-x64.zip`.
2. Распакуйте архив целиком в любую папку (например, `C:\ViralCut`).
3. Запустите `ViralCut.exe`.

Архив включает `FFmpeg`, модель `Whisper Small` и все встроенные шрифты. Контрольная сумма SHA-256 приложена в `SHA256SUMS-windows.txt`.
