# KrlzCut 2.0.0 — Большое студийное обновление

Полная перезагрузка интерфейса, рендера и редактора клипов под брендом **KrlzCut 2.0** (сохранена полная совместимость с существующей базой проектов `%APPDATA%\ViralCut`).

## Что нового

### Студийный интерфейс Apple Pro Dark и темы
- **5 разделов в боковой панели**: *Главная*, *Новый проект*, *Проекты*, *Очередь* и *Настройки* + карточка состояния GPU/кодировщика и модели Whisper внизу.
- **Главная (Dashboard)**: 3 карточки быстрого запуска режимов (*ИИ-нарезка*, *Нарезка стримов*, *Обычная нарезка FFmpeg*), недавние проекты с превью и **круговые индикаторы нагрузки CPU / GPU / RAM** в реальном времени.
- **6 тем оформления и своя 2-цветная палитра**: *Apple Pro Dark* (по умолчанию), *Cosmic Glass*, *Classic Amber*, *Emerald Studio*, *Ocean Pro* и конструктор градиентной палитры из любых 2 цветов с мгновенным применением.

### Режимы нарезки и Библиотека проектов
- **3 режима обработки**: *ИИ-нарезка* с **8 ИИ-пресетами** (*Лучшие, Смешное, Эмоции, Драма, Инсайты, Экшн, Цитаты, История*), *Нарезка стримов* и *Обычная нарезка FFmpeg* (быстрая нарезка без Whisper).
- **Sticky-карточка «Итог проекта»** справа на экране создания проекта.
- **Библиотека проектов**: фильтры (*Все / Готовые / В работе / Ошибки*), поиск, переключение *Сетка / Список*, панель быстрого предпросмотра справа и **переименование проектов** (`PATCH /api/projects/{pid}`).
- **Экран «Очередь»** для отслеживания активных задач рендера и истории.

### Мега-редактор клипа
- **Слой игры (Split-Screen)**: загрузка и удаление своих игровых роликов + встроенные процедурные фоны, пропорции разделения `50/50 · 55/45 · 60/40 · 65/35 · 70/30`, зум и панорамирование мышкой/колёсиком для верхнего и нижнего слоя, смещение старта и тихий микс звука игры.
- **Визуальный Filmstrip-таймлайн**: 10-кадровая раскадровка клипа с перетаскиваемыми ручками обрезки начала/конца и живым плейхедом.
- **Живые перетаскиваемые субтитры прямо в редакторе**: синхронизация слов с воспроизведением, перетаскивание мышкой прямо по видео, **5 анимаций** (`Нет / Pop / Fade / Slide / Bounce`), свой hex-цвет акцента, **настройки обводки** (вкл/выкл, толщина `0–14 px`, цвет обводки).
- **Генерация описания и хэштегов** по кнопке «✨ Сгенерировать».

### Менеджер моделей Whisper и качество рендера
- Встроенный менеджер локальных моделей Whisper в *Настройках*: скачивание, переключение и удаление `Small`, `Medium` и `Large v3 Turbo` с индикацией CUDA/CPU.
- Выбор качества рендера (*Быстро / Сбалансировано / Высокое*) и сохранённая упаковка свежего VC++ Runtime (`msvcp140.dll 14.40+`) для стабильной работы `ctranslate2`/Whisper на Windows.
