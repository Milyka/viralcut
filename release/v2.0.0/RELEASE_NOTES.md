# KrlzCut 2.0.0

- Новый интерфейс: 5 разделов (*Главная*, *Новый проект*, *Проекты*, *Очередь*, *Настройки*) и мониторинг CPU / GPU / RAM.
- 3 режима нарезки: по речи с 8 ИИ-пресетами, прямые эфиры и быстрая нарезка FFmpeg.
- Новый редактор клипа: Слой игры (Split-Screen), таймлайн с раскадровкой, живые перетаскиваемые субтитры, 5 анимаций, обводка и генерация описаний.
- Менеджер моделей Whisper (`Small`, `Medium`, `Large v3 Turbo`), темы оформления и переименование проектов.
