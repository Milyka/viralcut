# KrlzCut 2.0.1 — Редизайн по `DESIGN.md` и anti-slop стандартам

Полная переработка визуальной системы по строгому 9-секционному `DESIGN.md` (адаптировано с `runwayml` из `getdesign`) и правилам `design-taste-frontend`:

- **Монохромная Pro NLE-тема `KrlzCut Obsidian` по умолчанию**: глубокий обсидиановый фон (`#0A0A0B`), непрозрачные карточки с тонкой границей `1px` (`#111113` / `#18181B`), плоские контрастные кнопки `#FAFAFA` / `#09090B` — без фиолетового, неоновых размытий и градиентных кнопок.
- **5 новых тем без фиолетового** (*KrlzCut Obsidian*, *Cinema Amber*, *Studio Emerald*, *Engineering Cobalt*, *Director Red*) + конструктор **Своей 2-цветной палитры**.
- **Единая система монохромных SVG-иконок (`1.75px`)** во всех экранах и Мега-редакторе (полностью убраны эмодзи).
- **Прямой студийный копирайтинг** без шаблонных AI-фраз, чёткие подписи действий (`Создать проект`, `Открыть видеофайл`, `Перерендерить клип`, `Применить ко всем`) и `tabular-nums` на всей телеметрии и таймкодах.
- **Улучшенная читаемость круговых колец CPU / GPU / RAM** и исправленное перестроение Мега-редактора на узких экранах.
