# KrlzCut 2.0.1

- Обновлён интерфейс: спокойная тёмная тема **KrlzCut Obsidian**, 5 цветовых тем и настройка своей 2-цветной палитры.
- Новая навигация: *Обзор*, *Новый проект*, *Проекты*, *Очередь* и *Настройки* + мониторинг CPU / GPU / RAM.
- 3 режима нарезки (по речи с 8 ИИ-пресетами, прямые эфиры, быстрая нарезка FFmpeg).
- Новый редактор клипа: Слой игры (Split-Screen), таймлайн с раскадровкой, живые перетаскиваемые субтитры, 5 анимаций, обводка и генерация описаний.
- Менеджер моделей Whisper (`Small`, `Medium`, `Large v3 Turbo`) и переименование проектов.
