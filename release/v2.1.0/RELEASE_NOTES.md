# KrlzCut 2.1.0

- **Brand Kits (профили каналов)**: сохранение и применение пресетов канала в один клик — формат, субтитры, водяной знак (PNG/WebP), интро и аутро (до 15 с), фоновая музыка и настройки автоматизации.
- **Пул Слоя игры (случайный фон)**: теги для фоновых роликов и автоматический выбор случайного фона и стартового смещения для каждого клипа без повторов подряд.
- **Мультимодальный поиск моментов**: потоковый парсер повтора чата YouTube (`.live_chat.json`) и Twitch VOD, детектор звуковых всплесков (> +7 дБ) и передача топ-пиков хайпа в ИИ-подбор моментов.
- **Авто 2-спикерный сплит**: автоматическая 50/50 раскладка для подкастов и интервью с двумя ведущими и якорением субтитров по центру шва.
- **BGM Auto-Ducking и Hook Punch-In Zoom**: локальная библиотека фоновой музыки с FFmpeg `sidechaincompress` (авто-приглушение под речью) и плавный зум на первые 3 секунды клипа.
- **Telegram / Discord бот одобрения**: локальный исходящий бот со строгим белым списком пользователей (ID / `@username`), отправкой превью и кнопками `Approve` (автоэкспорт `.mp4` + `.srt` + `.txt`), `Skip` и `Regenerate Hook`, а также запуском новых проектов по ссылке из чата.
