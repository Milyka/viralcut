# KrlzCut v2.1.2

Патч-релиз с исправлением конкурентных гонок в Telegram / Discord ботах одобрения.

## Что исправлено

- **Неблокирующий Discord Gateway (`viralcut/bot_notify.py`)**: `INTERACTION_CREATE` выполняется фоновыми `asyncio.Task`, поэтому долгий `Regenerate Hook` больше не блокирует чтение `OP 11 HEARTBEAT_ACK` и параллельные нажатия кнопок.
- **Защита от `HTTP 409` и гонки перезапуска Telegram/Discord**: `restart_bots()` перезапускает только бота с изменившимся токеном или флагом включения; вытесненный поток больше не обрабатывает запоздалые апдейты и не затирает `last_error` активного бота.
- **Актуальный белый список в поллинге Telegram**: `app_settings.get()` перечитывается сразу после возврата `getUpdates`, поэтому удаление пользователя из `tg_allowed_users` действует мгновенно.
- **Мгновенная остановка наблюдателей `rehook` при выходе**: `_watch_rerender_and_push()` использует `_SHUTDOWN_EVENT.wait(...)`, корректно завершаясь при закрытии приложения без прерывания при сохранении настроек.
